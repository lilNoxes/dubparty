# 🎙️ DubParty

Вечеринка дубляжа: переозвучивайте любимые сцены из фильмов и мультфильмов вместе с друзьями с помощью смартфонов!

---

## 🎮 Как играть

1. **Хост (Экран ТВ / Компьютер):**
   * Открывает главную страницу игры (`/host`).
   * Выбирает сцену и нажимает **«Создать комнату»**.
   * На экране появляется 4-значный код комнаты и QR-код.
2. **Игроки (Смартфоны):**
   * Сканируют QR-код камерой телефона (открывается `/mobile`).
   * Вводят свое имя.
   * Каждый игрок автоматически получает своего персонажа (например: *«Твоя роль: Северус Снейп»* или *«Персонаж 1»*).
3. **Запись дублей:**
   * Хост запускает сцену.
   * Когда наступает очередь реплики игрока — его телефон вибрирует и загорается:
     * Суфлер показывает текст фразы и актерскую подсказку (например, *«[Шепотом, с паникой]»*).
     * Игрок нажимает **«Я ГОТОВ!»**.
     * Идет обратный отсчет **3... 2... 1...** и включается запись.
4. **Премьера:**
   * После записи всех реплик сервер за 1-2 секунды склеивает голоса игроков с оригинальным фильмом (приглушая оригинальную речь до 10%).
   * На экране ТВ начинается премьера полученного шедевра с возможностью пересмотреть, перезаписать или скачать готовое видео!

## ☁️ Размещение на https://dash.infrlo.com/ (Cloud Deploy)

Для деплоя на платформу Infrlo:

1. **Создайте репозиторий на GitHub** и загрузите туда проект (папки `backend`, `frontend`, `storage/movies`, файлы `run.py`, `requirements.txt`).
2. **В панели Infrlo:**
   * Подключите ваш GitHub-репозиторий.
   * **Команда установки зависимостей (Build Command):**
     ```bash
     pip install -r requirements.txt
     ```
   * **Команда запуска (Start Command):**
     ```bash
     python run.py
     ```
     *(или: `python -m uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT`)*
3. **Готово!** Сервис выдаст публичный постоянный HTTPS-домен, который стабильно открывается с любых телефонов в РФ без VPN и блокировок.

## 💻 Локальная подготовка новых сцен на ноутбуке (RTX 3060)

Тяжелые нейросети (faster-whisper и pyannote.audio) запускаются на вашем ноутбуке с видеокартой заранее, создавая готовые сцены:

```bash
# 1. Установите ML-зависимости (если еще не установлены):
pip install -r requirements-ml.txt

# 2. Подготовьте любую сцену от 15 секунд до 3 минут:
python prep_scene.py "storage/movies/harry_potter.mp4" --start 00:01:20 --end 00:03:40 --characters "Северус Снейп, Гарри Поттер" --output snape_scene.mp4
```

### Параметры `prep_scene.py`:
* `video` — путь к видеофайлу.
* `--start` / `--end` — таймкоды отрезка (например: `00:01:30` и `00:03:00`). Сцена нарезается без потери качества за 1 секунду.
* `--characters` / `-c` — имена персонажей через запятую (например: `"Шрек, Осел"`). Нейросеть свяжет реплики с этими именами.
* `--output` / `-o` — имя итогового файла сцены.
* `--model` / `-m` — размер модели Whisper (`tiny`, `base`, `small`, `medium`). По умолчанию `small`.

Скрипт автоматически сохранит готовый видеофрагмент и `_manifest.json` в папку `storage/movies/`.
